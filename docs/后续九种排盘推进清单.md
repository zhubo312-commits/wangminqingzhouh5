## 1. 状态定义

| 状态 | 含义 | 是否允许编码 |
|---|---|---|
| 待盘点 | 尚未确认算法来源、输入输出和专业结构 | 否 |
| 资料补充中 | 已定位部分来源，但 Definition of Ready 未完成 | 否 |
| 可开发 | 算法来源、脱敏样例、黄金结果和功能设计均已确认 | 是 |
| 开发中 | 单盘分支正在完成纵向链路 | 是 |
| 待验收 | 功能已完成，正在跑完整验证和三档视觉检查 | 仅修复 |
| 已验收 | Definition of Done 全部满足并已形成独立提交 | 已结束 |
| 阻塞 | 缺少必须由用户或外部系统提供的资料/权限 | 否 |

状态只能按证据更新，不能因为页面能打开就改成“已验收”。

## 5. Definition of Ready

一个盘种只有以下项目全部完成，状态才能从“待盘点/资料补充中”改为“可开发”：

- [ ] 用户名称、真实算法名称和旧系统对应关系已确认。
- [ ] `slug`、路由、`chartType` 和 Schema 版本已确认。
- [ ] 授权算法来源、文件/接口位置和版本/提交号已记录。
- [ ] 原始页面及全部必要子页面可访问，版本化脚本、采集时间和 SHA-256 已记录。
- [ ] 已实际操作全部起盘方式、条件显隐和结果工具，原始功能清单已保存。
- [ ] 新旧功能对照矩阵已完成，每项均标记为原样保留、等价重构、经确认移除或阻塞。
- [ ] 至少一份脱敏合法请求已保存。
- [ ] 对应原始响应已保存，字段含义已说明。
- [ ] 每种起盘模式至少一份可与可信来源核对的黄金结果已确认。
- [ ] 必填、选填、默认值、范围、互斥条件和错误边界已列出。
- [ ] 专业阅读路径已写出。
- [ ] 每组信息的显示层级已标注。
- [ ] 模块合并/拆分理由已说明。
- [ ] 智能老师入口需求已明确；默认结论为不提供。
- [ ] `docs/<盘种>页面功能设计.md` 已完成并确认。

## 14. 推荐排期规则

当前不根据名称直接给 P01–P09 排固定开发顺序。先完成资料盘点，再按以下顺序选择：

1. 算法来源已授权且能够本地复用。
2. 有脱敏请求、原始响应和可信黄金结果。
3. 专业阅读路径已由业务方确认。
4. 能验证公共底座，但不是结构极端的特殊盘种。
5. 对其他盘种复用价值较高、依赖较少。

如果多个盘种同时达到“可开发”，优先选输入输出边界最清楚、黄金结果最容易核验的一项。高风险或资料含糊的盘种保持“待盘点/阻塞”，不能为了排期强行开发。
