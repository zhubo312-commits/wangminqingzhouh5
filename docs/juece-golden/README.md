## 材料结构

每个 `case-XX` 目录包含：

- `request.json`：新版结构化请求。
- `reference-original.json`：参考站当前接口或生产脚本的原始结果及采集地址。
- `old-original.json`：旧包直接运行结果，仅保留为迁移证据，不再作为验收基准。
- `new-normalized.json`：本地 Java `ShijiaJueceEngine` 的标准化响应。
- `field-diff.json`：参考站字段到新版字段的逐项映射与差异。
- `result-390.png`：390×844 视口结果页。

`source-manifest.json` 固化参考站当前版本化脚本 URL、SHA-256、采集时间，以及旧包关键文件 SHA-256。执行 `npm run golden:juece` 会只读访问参考站并重建六组 JSON；执行 `npm run preview:juece` 可重建三档预览和六张 390px 结果图。

## 参考站真实口径

- 转盘结果页自 2025-03-13 起固定调用星河奇门接口；表单携带的置闰、茅山、手工局、日/月/年空及其他寄宫参数不会改变转盘结果。
- 因此新版转盘也固定为“拆补 · 时空 · 寄坤宫”，并在页面上直接说明，避免给用户无效选项。
- 飞盘仍执行参考站生产脚本中的时家决策算法，顺逆、定局和旬空选择均生效。
- 转盘真太阳时仍返回地区与校正结果，但参考站转盘使用原始钟表时间起局；新版保持一致。飞盘继续按真太阳时起局。
