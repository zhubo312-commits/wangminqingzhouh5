## 材料结构

每个 `case-XX` 目录包含：

- `request.json`：新版结构化请求。
- `old-original.json`：固定 SHA-256 旧包直接运行得到的原始数据。
- `new-normalized.json`：本地 Java `ShijiaJueceEngine` 的标准化响应。
- `field-diff.json`：旧字段到新字段的逐项映射与差异。
- `result-390.png`：390×844 视口的完整结果页。

`source-manifest.json` 记录迁移来源关键文件及 SHA-256。执行 `npm run golden:juece` 可在本地 Java 服务可用时重建 JSON；执行 `npm run preview:juece` 可重建三档预览和六张 390px 结果图。
