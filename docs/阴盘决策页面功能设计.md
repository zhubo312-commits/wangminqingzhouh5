# 阴盘决策页面功能设计

版本：1.0<br>
日期：2026-08-12<br>
路由：`/paipan/yinpan-juece`<br>
算法标识：`yinpan_juece`<br>
契约：`guoxue.paipan.yinpan_juece.v1`

## 1. 范围与依据

本盘对应参考站 `pages/yinpan`，不是决策学的时家转盘/飞盘配置页。算法使用仓库已经冻结的 `QiMenZao.getYinPanQiMen` 与 `QimenPan.getQimenPan`，与参考站当前 `app/qimen/getQimenH5` 同源。版本化脚本、原始请求/响应和 SHA-256 见 `docs/yinpan-golden/`。

页面只展示传统盘面结构及核验字段，不生成个案吉凶结论，不提供智能老师入口。

## 2. 输入

- 起盘日期与时间：必填，精确到分钟。
- 性别：男/女，默认男；用于保留参考站条件及可选终身局资料。
- 所排事项：选填，去除首尾空白，最多 30 字。
- 盘型：时盘或刻盘，默认时盘。
- 终身局：默认关闭；开启时附带同一时间、性别的四柱和大运资料。

时盘前后局按两小时移动，刻盘前后局按十分钟移动。为保持参考站现有行为，刻盘的“上一日/下一日”实际按两小时移动；页面不把它解释为民用自然日。

## 3. 输出与阅读顺序

1. 起局总览：事项、性别、阳历、阴历、四柱、空亡、阴阳遁局数、旬首、值符、值使、节气、月将和马星。
2. 阴盘九宫：宫序、卦名、方位、五行、八神、九星、八门、天地盘干、隐干、空亡、马星、值符和值使。
3. 宫位详情：四害、天盘十二长生、地盘十二长生。
4. 天门地户：十二地支对应关系，默认折叠。
5. 终身局资料：仅在请求开启时出现，展示阴历、生肖/星座、起运、格局参考和大运区间。
6. 标记说明与文化提示。

## 4. 功能对照矩阵

| 参考功能 | 新版处理 | 说明 |
|---|---|---|
| 日期时间 | 等价重构 | 使用全站移动滚轮选择器 |
| 性别 | 原样保留 | 男/女分段按钮 |
| 事项 30 字 | 原样保留 | 计数、边界和服务端校验一致 |
| 时盘/刻盘 | 原样保留 | 传递 `isKe=0/1` 对应语义 |
| 终身局 | 等价重构 | 不发第二个外部请求，由本地八字引擎生成 |
| 上一/下一局 | 原样保留 | 时盘 ±120 分钟，刻盘 ±10 分钟 |
| 上一/下一日 | 原样保留 | 时盘 ±1440 分钟，刻盘沿用参考站 ±120 分钟 |
| 九宫、四害、长生 | 等价重构 | 移动端三列，点击宫位展开详情 |
| 天门地户 | 等价重构 | 折叠显示 12 组完整数据 |
| 放大、重排 | 原样保留 | 放大弹层与返回表单 |
| 旧页面样式控制字段 | 移除 | 非算法输出，不进入公开契约 |
| 个案断语/智能老师 | 不提供 | 不在本盘范围内 |

## 5. 接口与状态

- `POST /api/v1/paipan/yinpan-juece/chart` 创建盘面和短期引用。
- `POST /api/v1/paipan/yinpan-juece/context` 按引用恢复同一份强类型上下文。
- `paipan_ref` 仅保存在当前标签页 `sessionStorage`；数据库仅保存哈希，并按 TTL 过期。
- Schema 版本或盘型不匹配时拒绝恢复。
- 重复提交由同步锁和禁用态阻止；换盘失败保留当前盘。

## 6. 移动端验收

360×780、390×844、430×932 均保持九宫三列且整页无横向溢出。主要按钮和选择控件触控高度不小于 44px，宫位按钮具备展开语义，放大层使用模态对话框语义，并沿用全站减少动态效果规则。
