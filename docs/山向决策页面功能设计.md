# 山向决策页面功能设计

版本：1.0<br>
日期：2026-08-12<br>
路由：`/paipan/shanxiang-juece`<br>
算法标识：`shanxiang_juece`<br>
契约：`guoxue.paipan.shanxiang_juece.v1`

## 1. 范围与依据

本盘对应参考站 `pages/shanxiang`，不是普通罗盘记录或时间奇门。参考页输入年份和 0～360 度山向，按角度所在十五度区间联排三组五度分金，并优先显示当前度数所属盘。算法使用仓库已有的 `QiMenZao.getShanXiangQiMen`、72 组五度山向表与 `QimenPan.getQimenPan`；这些冻结源码和参考站当前接口的黄金结果一致，运行时不依赖参考站。

页面只展示传统盘面结构及核验字段，不生成个案吉凶结论，不提供智能老师入口。版本化脚本、原始请求、黄金摘要和 SHA-256 见 `docs/shanxiang-golden/`。

## 2. 输入与边界

- 排盘年份：必填，1930～2100，默认当前年。
- 山向度数：必填，0～360，允许一位或更多小数；360 按 0 度所在分区计算。
- 所排事项：选填，去除首尾空白，最多 80 字；只随短期上下文保存，不参与算法。
- 分区规则：每十五度包含 `0/5/10` 三个五度起点；输入 7 度时显示顺序为 `5/0/10`，输入 360 度时为 `0/5/10`。

## 3. 输出与阅读顺序

1. 山向总览：年份、当前分金、度数范围、山、向和事项。
2. 三局切换：同一十五度区间的三组分金，当前所属盘优先。
3. 起局核验：年柱、山向时柱、阴阳遁局数、旬首、空亡、值符、值使、马星和黄泉八煞。
4. 九宫盘：宫序、卦名、方位、五行、八神、九星、八门、天地盘干、隐干及空/马/符/使标记。
5. 宫位详情：刑、墓、迫以及天地盘十二长生。
6. 放大查看、重新排盘与文化提示。

## 4. 功能对照矩阵

| 参考功能 | 新版处理 | 说明 |

| 三局切换 | 等价重构 | 使用可访问 tab 语义 |
| 山、向、度数范围 | 原样保留 | 每局独立显示 |
| 阴阳遁、局数、旬首、空亡 | 原样保留 | 作为黄金核验字段 |

| 九宫八神九星八门、天地盘、隐干 | 等价重构 | 移动端固定三列 |

## 5. 接口与状态

- `POST /api/v1/paipan/shanxiang-juece/chart` 创建三盘和短期引用。
- `POST /api/v1/paipan/shanxiang-juece/context` 按引用恢复强类型上下文。
- `paipan_ref` 仅保存在当前标签页 `sessionStorage`；数据库仅保存引用哈希并按 TTL 过期。
- Java 算法入口加同步保护，因为迁移的奇门实现含静态中间宫位状态。
- Schema 版本或盘型不匹配时拒绝恢复；无结果、恢复中、接口错误均有独立状态。

## 6. 移动端验收

360×780、390×844、430×932 均保持九宫三列且整页无横向溢出。输入、分金 tab、宫位和主要按钮满足至少 44px 触控高度；宫位具备展开语义，放大层使用模态对话框语义，并沿用全站减少动态效果规则。
